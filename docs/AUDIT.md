## Changes and review notes

Four new database regressions failed before migration 004: fictional verification escalation and three null-input proposals. They pass after it. Two further database tests verify privileged RPC boundaries, synthetic real-record flag invalidation and feedback privacy. Existing migrations were retained unchanged; deploy 004 in order.

The CSP change follows [Next.js nonce guidance](https://nextjs.org/docs/app/guides/content-security-policy), using the installed Next.js 15 middleware API. CI now installs managed Chromium before the production smoke that uses it. Browser tests own their server/data file and no longer delete the shared developer demo store. Vitest was upgraded to the patched 4.1.11 line, with Vite 8 automatic JSX configuration and a Node >=22.12 engine floor.

No real listing, hosted deployment, repository/PR, account, external communication, alert receiver, data-retention approval or founder release approval was created. No sensitive household research data was collected. `readiness:release` must continue to exit 1 for LAUNCH-01 through LAUNCH-07.
